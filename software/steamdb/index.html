CLI Tool

steamdb

A terminal CLI that looks up Steam games by name and draws an ASCII chart of concurrent players over time. Search the Steam Store, read the live player count, and plot history from SteamCharts — no API key required.

Key features

  • Search Steam by game name or jump straight to an AppID.
  • Live concurrent player counts from Steam’s Web API.
  • History windows from 24 hours to all-time, rendered as a Braille graph.
  • Optional color, legend, and non-interactive pick flags for scripting.
